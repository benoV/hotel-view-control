SUPPORT

Simple controls for hotel search results.

Getting started

Install Hotel View Control from the Chrome Web Store, then open a supported hotel search-results page and use the small control over a hotel image to hide, dim, or restore that listing. Click the extension icon in the browser toolbar to review and restore saved preferences.

Supported sites

Hotel View Control currently supports Booking.com and Agoda search-result pages. The extension is independent and is not affiliated with, endorsed by, or sponsored by Booking.com, Agoda, Loom, or their parent companies.

Get help

For a bug report or feature request, open an issue in the public project tracker. Please include the site, the page type, and a screenshot when possible.

Privacy

Hotel View Control processes only the hotel-card details required for a user-selected hide or dim preference. Those preferences stay in Chrome extension storage on the device and are never transmitted externally. Read the complete privacy statement.
